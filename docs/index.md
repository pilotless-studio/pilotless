# pilotless

Most of what a first manager does is ask people what they did this week and write it down. That part is automatable.

- **[Install the pilotless GitHub App](https://pilotless-web-o53cqe2tiq-ew.a.run.app/install?src=pages.home)** - free. Every Monday it updates one pinned issue per repository: what shipped, what is in flight, which pull requests stalled, who moved code.
- **[Open source issues nobody has picked up](status/unowned.html)** - one aggregated list, across 30 well-known projects, of work sitting in a queue nobody is watching. Regenerated every Thursday.
- **[Weekly status pages](status/)** - the same report for 30 well-known public repositories. Unofficial, removable on request.
- **[pilotless status action](https://github.com/pilotless-studio/pilotless#status-action)** - the same report inside your own CI. Two lines of YAML, no account.

Guides: [weekly status report from GitHub](weekly-status-report.html) · [stale pull request reminders](stale-pull-request-reminder.html) · [GitHub standup bot without the standup](github-standup-bot.html)
